# data display

Token-driven components for inspecting and presenting workbench data:

- `Card` provides a bordered surface with optional heading, actions, body, and footer snippets.
- `Table` renders accessible, horizontally scrollable tabular data from columns and rows.
- `KeyValue` renders property and metadata lists in one or two columns.

These components are presentational. Selection, sorting, pagination, and service
state remain owned by the consuming feature.
