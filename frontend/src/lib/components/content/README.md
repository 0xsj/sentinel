# content utilities

Compact identity and code surfaces for the workbench:

- `Tag` (also exported as `Chip`) presents small semantic metadata labels.
- `Avatar` presents a person or workspace identity with initials and optional status.
- `CodeBlock` and `InlineCode` preserve developer-facing content with token-driven typography.
- `CopyButton` performs a local clipboard copy and reports success through `onCopy`.

These components do not own feature state, syntax highlighting, or identity services.
